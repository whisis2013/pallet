# 승광 팔레트 적재표 – QR 뷰어

파레트 적재 품목,수량,로트번호,유통기한 등 정보

주식회사 승광인터내셔널 베트남 수출 팔레트의 QR 라벨을 찍었을 때 열리는 화면입니다.

- 이 저장소에는 **화면(뷰어)만** 있고 팔레트 데이터는 없습니다.
- 적재 내용은 QR 라벨의 주소 뒷부분(`#v1.…`)에 담겨 있어서, 라벨을 찍은 휴대폰에서만 화면에 표시됩니다. 주소의 `#` 뒷부분은 서버로 전송되지 않습니다.
- 입력·수정과 QR 라벨 출력은 Claude의 「승광 팔레트 적재표」에서 합니다.
- 주소: https://whisis2013.github.io/pallet/
